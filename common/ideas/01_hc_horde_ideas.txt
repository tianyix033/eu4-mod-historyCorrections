# HistoryCorrections
#
# National ideas for the Kazakh Khanate and the Zunghar (Dzungar) Khanate.
#
# Both tags ship with full histories and no ideas at all, so before this they
# fell through to generic sets. Now that decisions/zz_horde_identities.txt can
# actually form them, and the culture-shift events make that reachable, they
# need something of their own - particularly for the later start dates, where
# both were real powers rather than curiosities.
#
# File naming matters here. The engine assigns the first idea group a country
# is eligible for, searching files alphabetically, so this sorts after
# 00_country_ideas.txt but ahead of zz_group_ideas.txt and zzz_default_idea.txt
# and therefore beats the generic fallback.
#
# This is a new file, not a copy of a vanilla one, so no @ markers are needed.
