# HistoryCorrections
#
# Kazakh, Khalkha, Zunghar and Khoshuud exist as tags with full histories but
# have no formation decision, so they essentially never appear in a game.
#
# These are reactive rather than aspirational. The gate is already being a
# horde of the matching primary culture and holding the historical seat -- a
# horde does not set out to become these, it discovers that it has.
#
# The AI always takes it (ai_will_do factor 1) because by the time it
# qualifies, the identity has already changed in everything but name.
#
# On the cultures: khazak and khalkha are unique to their tags, so they gate
# directly. Zunghar and Khoshuud cannot, because their historical culture
# (oirats) is shared by six tags and the Oirat Horde already owns Kobdo at the
# 1444 start -- it would have formed Zunghar on day one. They instead gate on
# the culture of the people each ended up ruling: uyghur for the Dzungars over
# the Tarim oases, tibetan for the Khoshuud under Gushri Khan. Neither
# combination exists in 1444; no horde starts with either culture.
#
# No ideagroups.1 swap is offered: none of these four tags has national ideas
# of its own, so a swap could only move them off what they already hold.
