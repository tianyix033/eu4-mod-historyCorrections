# HistoryCorrections
#
# Kazakh, Khalkha, Zunghar and Khoshuud exist as tags with full histories but
# have no formation decision, so they essentially never appear in a game.
#
# These are reactive rather than aspirational. The only gate is already being a
# horde of the matching primary culture -- there is nothing to conquer toward.
# A Mongolia reduced to its Khalkha provinces, pressured into switching primary
# culture, has in effect become the Khalkha; this lets the tag follow.
#
# The AI always takes it (ai_will_do factor 1) because by the time it qualifies
# the identity has already changed in everything but name.
#
# khazak and khalkha are unique to their tags. oirats is shared by six tags,
# so Zunghar and Khoshuud additionally require their historical capital --
# Kobdo for Dzungaria, Tsaidam for the Khoshuud in Qinghai.
#
# No ideagroups.1 swap is offered: none of these four tags has national ideas
# of its own, so a swap could only move them off what they already hold.
